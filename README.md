🎓 Student Tracker MERN - Modern Edition

The Student Tracker is a **premium full-stack web application** built using the MERN stack (MongoDB, Express.js, React, Node.js).
It provides a powerful and visually stunning way to manage student records, perform CRUD operations, and visualize student information through a **modern, gradient-rich, and fully responsive UI** with advanced animations and glass morphism effects.

✨ Features

📌 **Modern Student Information Management**
- 🆔 **Student ID**: Unique identifier with professional validation
- 👤 **Name**: Full name with elegant typography
- 📞 **Phone**: Contact number with formatted display
- 📧 **Email**: Email address with validation styling
- 🎓 **Grade**: Student's grade/class with color-coded badges

📌 **Advanced CRUD Operations**
- ➕ **Create**: Add new student records with animated forms
- 📖 **Read**: View student details in beautiful card layouts
- ✏️ **Update**: Modify student information with smooth transitions
- ❌ **Delete**: Remove student entries with confirmation modals

- 📱 **Fully Responsive**: Optimized for desktop, tablet, and mobile devices

🚀 Getting Started

Follow these steps to set up the **modern Student Tracker** locally:

### 1️⃣ Clone the repository
```bash
git clone https://github.com/your-username/student-tracker-mern.git
cd student-tracker-mern
```

### 2️⃣ Install dependencies

**For backend:**
```bash
cd server
npm install
```

**For frontend:**
```bash
cd client
npm install
```

### 3️⃣ Configure environment variables

Create a `.env` file inside the **server** folder with the following:
```env
MONGODB_URI=your-mongodb-connection-string
PORT=8000
```

### 4️⃣ Run the server
```bash
cd server
npm start
```
*Server will run on http://localhost:8000*

### 5️⃣ Run the client
```bash
cd client
npm start
```
*Client will run on http://localhost:3000*

### 🎉 **Experience the Modern UI**
👉 Open **http://localhost:3000** in your browser to enjoy the beautiful, gradient-rich interface with smooth animations!
